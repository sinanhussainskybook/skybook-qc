Decisions

Decided

  • D1Database: Supabase PostgreSQL, QC's own project
  • D2Users created from the command line; admin and designer roles; no sign-up
  • D3Logos in a private Supabase Storage bucket; one per company
  • D4Platform values from Meta, LinkedIn, YouTube and Google Ads pages; typed size for banners, print, slides, other
  • D5Gemini API (Google AI Studio, free tier) for static designs, one call per design; Local AI and Google Cloud kept in the code, paused
  • D6Video read with FFmpeg on our server; first 15 min, up to 120 frames
  • D10Railway: the app and a worker on a persistent Node host; database queue
  • D8Report: a PDF made on download, never stored; Arabic supported (Noto fonts); dates in Dubai time
  • D11QC sessions are temporary: deleted 24 h after the last change; video up to 50 MB (Free plan)
  • D12Golden Rules saved per company, used in every QC check; reported with the other issues, only when broken
  • D13Company access by membership; admins see every company

What the app keeps

Saved permanently

  • Users and sign-in
  • Companies, contact details and logo
  • Brand guidelines
  • Golden Rules

Temporary only (deleted after 24 h)

  • The content being checked and supporting files
  • Requirements for the current check
  • The platform chosen and the measured size / length of the content
  • Analysis results (what was read in the content) — only the latest
  • Never kept: QC history, past designs, reports
